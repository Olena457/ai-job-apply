## **UNDER DEVELOPMENT**

#### * 🚧Please note: This application is currently in early development. It is not fully functional or live yet.*

This project is built using a modern full-stack TypeScript ecosystem.

### Frontend (`/web`)
* **Framework:** [Next.js](https://nextjs.org/) (v16)
* **UI Library:** [React](https://react.dev/) (v19)
* **Language:** TypeScript
* **Code Quality:** ESLint

### Backend (`/api`)
* **Framework:** [NestJS](https://nestjs.com/) (v11)
* **HTTP Server:** Express (under the hood)
* **Language:** TypeScript
* **Testing:** Jest (Unit & E2E Testing configured)
* **Code Quality & Formatting:** ESLint & Prettier
